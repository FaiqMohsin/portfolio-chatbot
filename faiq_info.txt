Project 1: Cortex — AI Study Assistant (2026)
Cortex is my flagship AI engineering project. It is a production-ready RAG-based study assistant that lets students upload their PDF study materials and interact with them intelligently through natural language. The problem it solves is that students have large amounts of study material but struggle to find specific information quickly, generate practice questions, or get concise summaries for revision.

Features of Cortex:
- Ask Questions: students can ask any question about their uploaded documents and get accurate answers retrieved directly from their content
- Generate Quiz: the system automatically generates multiple choice practice questions on any topic from the documents
- Summarize: students get concise exam-focused bullet-point summaries of any topic
- Multi-document support: multiple PDFs can be uploaded and searched together
- Source citation: every answer shows which document it came from

How Cortex works technically:
The student uploads a PDF. The system extracts text from every page using PyPDF. The text is split into 500 character chunks with 50 character overlap to preserve context at boundaries. Each chunk is converted to a vector embedding using Cohere embed-v4.0. The embeddings are stored in ChromaDB. When a student asks a question the question is also converted to an embedding. ChromaDB finds the most semantically similar chunks using cosine similarity. The top 4 chunks are retrieved and injected into a prompt as context. Cohere command-a-plus LLM generates an answer using only that retrieved context. This prevents hallucination because the AI only answers from the actual documents.

Project 2: SmartBMS — IoT and Deep Learning Battery Health System (2026)
SmartBMS is my Final Year Project at NUML University. It is a complete IoT-enabled predictive maintenance system for monitoring and predicting battery health in real time. The problem it solves is that millions of Pakistani households depend on lead-acid UPS batteries as backup power during load-shedding, but have no way to predict when the battery will fail until it actually dies.

Features of SmartBMS:
- Predicts State of Health (SoH) — how much capacity the battery has left
- Predicts State of Charge (SoC) — current charge level
- Predicts Remaining Useful Life (RUL) — how many charge cycles left before end of life
- Real-time monitoring via Flutter Android dashboard
- SHAP explainability — plain language explanations of why the battery is degrading
- Dual-mode communication — WiFi primary with Bluetooth fallback for Pakistan's unreliable internet
- On-device TFLite inference — works offline when internet is down
- Automated relay control — automatically cuts off load or charger based on thresholds
- Total hardware cost under PKR 2700

Technical details:
Applied transfer learning from NASA PCoE Li-ion benchmark dataset to a 620 million row real-world lead-acid battery dataset from Oxford University (BBOXX solar installations in Africa) achieving less than 2.5 percent RMSE accuracy. Used LSTM neural network for SoH prediction, Random Forest for SoC, and XGBoost for RUL. Integrated SHAP explainability with DeepExplainer and TreeExplainer to generate plain language diagnostic messages. Built a dual-mode WiFi and Bluetooth communication pipeline using ESP32 microcontroller. Deployed FastAPI backend on Render.com free tier with Supabase PostgreSQL database. Built Flutter Android app with real-time gauges, historical trend charts, anomaly highlighting, and PDF health report generation.

Tech stack: Python, TensorFlow, PyTorch, XGBoost, SHAP, FastAPI, Flutter, Dart, TFLite, ESP32, Supabase PostgreSQL, Render.com
